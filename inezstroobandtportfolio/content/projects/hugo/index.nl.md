## Projectoverzicht

Dit project is mijn persoonlijke portfolio website. Ik heb die gebouwd zodat ik mijn projecten, cv en een beetje van mijn writing op één plek kon tonen.

Ik koos voor Hugo omdat het volgens mij goed past bij een portfolio met veel content. Zo kon ik de structuur netjes houden en tegelijk werken in het Engels en Nederlands zonder alles dubbel te moeten maken.

Ik heb Hugo ook geleerd door een paar YouTube-video’s te volgen. Daardoor snapte ik de basis sneller en kreeg ik beter zicht op hoe ik de site kon opbouwen.

## Hoe Ik Het Bouwde

Ik begon met een Hugo theme en werkte dat daarna stap voor stap verder uit. De site bestaat uit contentbestanden, templates, CSS en een klein beetje JavaScript.

De inhoud staat in Markdown, zodat ik die makkelijk kan aanpassen. Daarnaast voegde ik tweetalige content toe, zodat bezoekers kunnen schakelen tussen Engels en Nederlands.

Voor het ontwerp gebruikte ik de Hugo Narrow theme als vertrekpunt. Daarna heb ik de typografie, spacing, navigatie en projectkaarten aangepast zodat het meer als mijn eigen portfolio aanvoelt.

## Features

- Tweetalige pagina’s in het Engels en Nederlands
- Projecten, cv en blog in één website
- Responsive layout voor desktop en mobiel
- Aangepaste templates en styling bovenop Hugo
- Snelle generatie als statische site
- Inhoud makkelijk aanpasbaar via Markdown

## Gebruikte Technologieën

De portfolio is gebouwd met Hugo, Markdown, HTML, CSS en JavaScript. Ik gebruikte ook Git voor versiebeheer en de structuur van een Hugo theme als vertrekpunt voor het project.

## Uitdagingen en Oplossingen

Een uitdaging was de site overzichtelijk houden terwijl ze twee talen ondersteunt. Dat loste ik op door de content op te splitsen in taalgebonden bestanden en de gedeelde structuur in de templates te houden.

Een andere uitdaging was de portfolio meer eigen laten aanvoelen in plaats van gewoon theme-achtig. Ik ben blijven sleutelen aan de layout en styling tot het goed voelde.

## Toekomstige Verbeteringen

- Meer screenshots toevoegen voor elk project
- De visuele storytelling op de homepage verder verbeteren
- De projectpagina’s uitbreiden met meer procesdetails
- Het design blijven verfijnen wanneer ik nieuwe projecten toevoeg
