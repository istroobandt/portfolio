## Project Overview

This project is my personal portfolio website. I built it so I could show my projects, resume, and a bit of my writing in one place.

I chose Hugo because it seemed like a good fit for a portfolio with a lot of content. It also made it easier to keep the structure clean and work in both English and Dutch without having to build everything twice.

I also learned Hugo by watching a few YouTube tutorials, which helped me get the basics faster and gave me a better idea of how to set up the site.

## How I Built It

I started from a Hugo theme and then changed it step by step. The site is made up of content files, layout templates, CSS, and a bit of JavaScript.

The content is written in Markdown, so it stays easy to update. I also added bilingual content so visitors can switch between English and Dutch.

For the design, I used the Hugo Narrow theme as the base. After that, I adjusted the typography, spacing, navigation, and project cards so it felt more like my own portfolio.

## Features

- Bilingual pages in English and Dutch
- Project, resume, and blog sections in one site
- Responsive layout for desktop and mobile
- Custom templates and styling on top of Hugo
- Fast static-site generation
- Easy content updates through Markdown

## Technologies Used

The portfolio is built with Hugo, Markdown, HTML, CSS, and JavaScript. I also used Git for version control and the Hugo theme structure as a starting point for the project.

## Challenges and Solutions

One challenge was keeping the site organized while supporting two languages. I solved that by separating the content into language-specific files and keeping the shared structure inside the templates.

Another challenge was making the portfolio feel less like a theme and more like my own site. I kept tweaking the layout and styling until it felt right.
